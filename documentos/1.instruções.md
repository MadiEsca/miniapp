# Instruções 

Uma rota quer dizer basicamente: Quando uma requisição de tal tipo for feita para determinada URL, execute a função que foi descrita

|views/templates| <-> |Controller| <-> |Repositories| <->|Models| OU |view| <--rotas--> |Controller| <-> |Repositories|

Dessa forma, quando uma rota é "acionada", o controller daquela rota é responsável por interligar o template com o(s) models

---

Esse projeto está sendo criado utilizando como base 2 bancos de dados, o mysql, que será utilizado em produçõa e hospedado no docker; e o sqlite3 que está sendo utilizado apenas para testes e configurações iniciais.

Dentro do sqlite3 o %s não funciona da mesma forma que no mysql, sendo necessário utilizar ? para que essa substitiução ocorra.

# Formulários com Flask

Dentro da pasta de mesmo nome, irei armazenar as classes que serão utilziadas para a construção dos formulários, em flask.

flask_wtf -> é a biblioteca utilizada para criação de formulários dentro do flask

---

Quando criamos um formulário por meio do flask_wtf, é necessário 
definir a SECURITY_KEY, que pode ser qualquer valor, decido por quem está criando. Essa SECURITY_KEY funciona para garantir a integridade dos dados que estão sendo enviados para o host, ou seja, se a chave definida for a mesma tanto no envio quanto no recebimento das informações, quer dizer que a comunicação é segura.

---
**Validações** - *WTFORMS* - Feito dentro da classe do formulário

Por meio da biblioteca wtforms é possível realizar validações nos campos do formulário. Como definir que um campo é obrigatório, não apenas no html, validar um email, definir que um campo DEVE ser igual a outro, como é o caso de uma senha, entre outros

> ***DataRequired*** VS ***InputRequired*** -> *DataRequired* verifica se determinado local foi **preenchido com dados ==não nulos==**, de forma que 0, ' ' (espaços vazios), entre outros, **não são considerados dados**. Enquanto o *InputRequired* verifica apenas se algo foi digitado dentro do campo, indepentende se é um espaço em branco, zeros ou outras coisas que não são consideradas pelo DataRequired

Para que as validações sejam aplicadas, é necessário dizer isso de forma explicita ao flask, por meio da declação:
```python
formulario.validate_on_submit()
```
>Bem, deixando um pouco mais claro, mesmo sem essa chamada de função os validadores já iriam funcionar, mas para que seja possível acessar os erros referentes a esses campos, como por exemplo, um determinado campo (senha) não correposnde com outro (confirmar senha), de forma que ele irá gerar um erro que só poderemos acessar caso **validemos a submissão**.

**Validadores Legais** - Email, DataRequired, InputRequired, EqualTo ...

O parâmetro _validators_ recebe uma **lista** de argumentos
